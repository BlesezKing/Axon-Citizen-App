# AXON CITIZEN — actualizaciones

Esta carpeta la lee la autoactualización de AXON CITIZEN (Ajustes → Actualizaciones):

- `latest.json`: número de versión, archivo y firma SHA-256.
- `AXON-CITIZEN-update-vN.zip`: la versión (sin los modelos de OCR).

No hace falta tocar nada aquí a mano: cada versión nueva sustituye a estos dos archivos.
